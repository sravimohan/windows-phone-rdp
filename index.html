Microsoft Remote Desktop on Windows 10 Mobile

A practical 2026 guide to sideloading the old Microsoft Remote Desktop client on a Windows 10 Mobile phone and connecting it to Windows 11 Pro.

Tested configuration:
Nokia Lumia 1520 · Windows 10 Mobile 1607 · OS build 10.0.14393.2551 · ARM32
Microsoft Remote Desktop 8.1.9.17 · Windows 11 Pro host

What this does

This turns an old Windows 10 Mobile phone into a usable RDP client. The phone displays and controls a full Windows desktop over the local network. It is not HDMI input and it does not turn the phone into a native wired monitor.

1. Enable Developer Mode and Device Portal

On the phone, open:

Settings → Update & security → For developers

Enable:

  • Developer mode
  • Device discovery
  • Device Portal

For a trusted home LAN, authentication can be temporarily disabled while installing the package.

Modern browser TLS problem: Windows 10 Mobile's Device Portal HTTPS certificate/TLS stack is old enough that current Edge may refuse the connection completely. In the tested setup, plain HTTP worked:
http://PHONE-IP
Example: http://192.168.4.25

2. Obtain the Microsoft Remote Desktop ARM package

The package that worked in the tested setup is:

Microsoft.RemoteDesktop_8.1.9.17_arm__8wekyb3d8bbwe.appx
PropertyValue
ArchitectureARM / ARM32
Package version8.1.9.17
Microsoft Store product ID9WZDNCRFJ3PS
Expected sizeabout 3.75 MB
SHA-17a27f3a0dd09abdcd59a58d96acb793a1ed0df8d

One way to locate the archived package is the RG-Adguard Microsoft Store link generator:

https://store.rg-adguard.net/

Select ProductId, enter 9WZDNCRFJ3PS, choose Retail, and generate the links. Find the exact ARM file shown above.

Verify the actual download host. The package link returned for this file should point to Microsoft's delivery infrastructure, such as:
*.dl.delivery.mp.microsoft.com
*.delivery.mp.microsoft.com
RG-Adguard is only being used to discover the Store package URL; the APPX itself should be downloaded from a Microsoft delivery hostname.
Do not re-host the APPX. This repository intentionally does not redistribute Microsoft's application binary. Download it from Microsoft's delivery infrastructure and verify the file before installing it. Temporary Microsoft CDN links expire, so a generated download URL should not be treated as a permanent link.

Verify the downloaded APPX

On Windows, run PowerShell in the folder containing the file:

Get-FileHash .\Microsoft.RemoteDesktop_8.1.9.17_arm__8wekyb3d8bbwe.appx -Algorithm SHA1

The expected SHA-1 for the package used in this guide is:

7A27F3A0DD09ABDCD59A58D96ACB793A1ED0DF8D

If the hash differs, do not install the file.

Do not use ARM64, x86 or x64 packages on a Lumia 1520.

Possible dependency

If deployment reports a missing Visual C++ dependency, the matching ARM phone framework from the same Store results is:

Microsoft.VCLibs.120.00.Phone_12.0.30113.0_arm__8wekyb3d8bbwe.Appx

On the tested phone, Remote Desktop installed without manually installing this dependency.

3. Sideload with Windows Device Portal

From a PC on the same network, open the phone's Device Portal using HTTP:

http://PHONE-IP

Open App Manager, choose the Remote Desktop APPX, and deploy it.

After deployment, check the phone's app list for Remote Desktop and launch it.

4. Enable Remote Desktop on Windows 11 Pro

On the Windows 11 PC:

Settings → System → Remote Desktop → On

Windows 11 Pro, Enterprise or Education can host an incoming Microsoft RDP session. Windows 11 Home cannot use the built-in RDP host.

Find the host's LAN IP address:

ipconfig

Use the active adapter's IPv4 address as the PC address in the Lumia Remote Desktop app.

5. Username formats

Local Windows account

PCNAME\username

You can confirm the exact form by running:

whoami

Microsoft account

MicrosoftAccount\your-email@example.com

Use the Microsoft account password, not the Windows Hello PIN.

6. Windows Hello / Microsoft account authentication workaround

If Windows 11 normally uses Windows Hello/PIN and the old Lumia RDP client rejects otherwise-correct Microsoft account credentials, run this once on the Windows 11 host:

runas /u:MicrosoftAccount\YOUR_EMAIL winver

Enter the Microsoft account password when prompted. Nothing is displayed while typing the password.

After winver launches successfully, retry the Lumia connection using:

Username: MicrosoftAccount\YOUR_EMAIL
Password: your Microsoft account password
This workaround succeeded on the tested Windows 11 Pro system while leaving Windows Hello and PIN enabled for normal local sign-in.

7. Connect from the Lumia

In Microsoft Remote Desktop on the phone:

  1. Add a new PC.
  2. Enter the Windows 11 PC's IPv4 address.
  3. Add the appropriate credentials.
  4. Connect and accept the local certificate prompt if shown.

Landscape orientation works well on the Lumia 1520's 1920×1080 display. Touch input is passed through to the remote desktop.

Troubleshooting

ProblemTry
Edge refuses Device Portal HTTPSUse http://PHONE-IP instead of HTTPS on a trusted LAN.
APPX says wrong architectureMake sure the package filename contains _arm__, not ARM64/x86/x64.
Missing VCLibs dependencyInstall Microsoft.VCLibs.120.00.Phone_12.0.30113.0_arm..., then retry.
RDP credentials rejected with Windows HelloUse the Microsoft account password, then try the runas workaround above.
Windows 11 Home hostThe built-in Microsoft RDP server is unavailable; use Pro/Enterprise/Education or another remote-desktop solution.

Scope

This guide documents a setup that was actually tested on a Lumia 1520 running Windows 10 Mobile 1607. The same ARM package may work on other Windows Phone / Windows 10 Mobile devices, but that has not been verified here.
